# Advent of Code 2023

Solutions pour l'Advent of Code 2023 (https://adventofcode.com/2023).
Les énoncés et les entrées ne sont pas inclus, à la demande du créateur d'Advent of Code : chaque solution lit son entrée dans un fichier `input` placé dans le dossier du jour, à récupérer sur le site, et affiche les réponses des deux parties.

Tout est en Python 3. Dépendances ponctuelles : `portion` (jour 19), `numpy` et `sympy` (jour 24), `networkx` (jour 25) ; les fichiers `visualisation.py` utilisent `PIL` ou `pyvis`.
